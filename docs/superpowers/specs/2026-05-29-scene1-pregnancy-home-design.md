# Scene1 怀孕首页接入设计

**日期：** 2026-05-29  
**目标：** 按现有 `scene1` 的接入方式，把“怀孕身份首页”复现为独立页面，并从 `scene1` 顶部模式切换进入。  
**本次范围：** 只做怀孕首页接入与可用，不扩展怀孕身份的消息页、我的页、详情流程。  

---

## 1. 背景与约束

当前项目已经验证过两条可复用路径：

- `备孕`：独立首页 + 独立路由 + 复用 `scene1` 手机壳与底部 tab
- `育儿`：独立首页 + 独立路由 + 复用 `scene1` 手机壳与底部 tab

这次 `怀孕` 必须沿用同一模式，避免把导出 zip 里的独立 React 工程整包搬进现有代码库。

已确认的硬约束：

- 保持现在项目的 `scene1` 风格
- 只做“怀孕首页接入 + 可用”
- 最小改动
- 路由仍然使用现有 `HashRouter`
- 不改坏 GitHub Pages 现有公开地址和发布方式

用户新增强调：

- **对原稿的高宽、间距、卡片比例、图标尺寸要做针对性审核复现**
- 不能只做视觉大意接近，必须把主要模块的布局比例尽量贴近原稿

## 3. 页面结构设计

怀孕首页按导出稿拆为 6 个语义块，避免把 Pixso 导出里的碎片组件原样搬入。

### A. 顶部日期切换条

包含：

- `回今天`
- 三个日期/孕周片段

作用：

- 作为首屏顶部导航区
- 与备孕页顶部日期条同级，但视觉样式按怀孕稿复现

### B. 怀孕主信息卡

包含：

- `距离预产期`
- 天数主数字
- `身长 / 体重 / 周数`

作用：

- 作为首屏核心主视觉
- 承担怀孕身份最强的识别信息

### C. 五宫格快捷入口

复现导出里的 5 个入口：

- 问医生
- 能不能吃
- 产检时间表
- hCG 查询
- 孕期体重

作用：

- 与备孕页工具区、育儿页快捷入口保持同类模块位置
- 只做静态入口复现，不展开后续跳转链路

### D. 宝宝变化 / 妈妈变化卡

包含：

- `宝宝变化`
- `妈妈变化`
- 一段说明文案

作用：

- 作为怀孕身份特有内容块
- 是本页第二个最重要的视觉识别模块

### E. 中部推荐功能 / 服务区

复现导出里的能力入口和服务推荐，例如：

- 孕妈护肤
- 月嫂报价
- 宝宝记
- 同城孕妈群
- 能不能做

作用：

- 填充首页中部推荐区
- 只保留静态可审查展示，不扩展新业务流程

### F. 内容卡与签到卡

包含：

- 一张社区内容卡
- 一张 `每日签到挑战 +5`

作用：

- 与备孕页内容卡区保持相似信息密度
- 作为首页末端内容区

## 5. 高宽与间距复现标准

这是本次最重要的非功能性要求。

### 5.1 复现原则

实现时不能只按“语义相似”去拼 UI，必须按导出稿做一轮数值审核。

审核重点：

- 各主卡片宽度
- 各主卡片高度
- 模块上下间距
- 卡片内边距
- 图标容器尺寸
- 文本与图标之间的 gap
- 栅格列宽与行距
- 底部 tab 与滚动内容之间的安全区

### 5.2 复现方式

以导出稿中 `Frame366.tsx` 与 `Frame366.css` 为尺寸基线，但不照搬其类名体系。

执行方式：

1. 从导出稿读取主要模块的原始尺寸与坐标关系
2. 提炼成现有项目中的语义类名
3. 仅对关键模块保留必要的像素级尺寸
4. 避免把整页写死成固定高度

### 5.3 允许固定、禁止固定

**允许固定：**

- 单个卡片高度
- icon 容器尺寸
- 某些视觉插图尺寸
- 模块间精确 gap

**禁止固定：**

- 整个页面根容器写死 `812px`
- 滚动区被写死到无法自然滚动
- 底部 tab 因固定高度被挤出手机壳

### 5.4 页面高度策略

导出稿里存在整页 `812px` 的静态画板高度，但在现有项目中不能直接照搬到页面根节点。

正确做法：

- 页面根容器使用现有壳子布局逻辑
- 滚动区单独承担内容高度
- 底部 tab 固定留在壳子底部
- 页面底部给滚动内容预留 tab 安全区

### 5.5 审核通过标准

本次实现完成后，至少满足：

- 首屏主卡比例接近原稿
- 快捷入口宫格宽高、间距与原稿接近
- 变化卡与推荐区上下节奏接近原稿
- 手机壳内滚动正常
- 底部 tab 完整可见

## 6. 素材策略

### 只提取必要素材

从 zip 中只拷贝怀孕首页真实使用的素材，不整包复制导出工程里的：

- 组件文件
- 样式文件
- 字体文件
- 未使用图片

### 图片优化

对明显偏大的图片：

- 优先转 `webp`
- 保持视觉可审查前提下压缩体积

### 图片加载策略

非首屏图保持：

- `loading="lazy"`
- `decoding="async"`
